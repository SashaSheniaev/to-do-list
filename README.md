## Локальний запуск без входу в Expo

```sh
npm install
npm start
```

`npm start` показує вибір: Android-телефон, Android-емулятор/USB, iPhone через Safari або браузер. Виконувати `npx expo login` для локального сервера не потрібно: ця окрема команда завжди відкриває запит входу.

Для iPhone обери **3 — iPhone: Safari** (або просто натисни Enter) чи виконай `npm run ios`. Запуск показує HTTP-посилання для Safari без QR-коду й меню Expo Go. Обидва пристрої мають бути в одній Wi-Fi мережі; з кількох адрес обери IP комп’ютера в цій мережі. Це вебверсія застосунку, а не нативна iOS-збірка. `npm run web` також запускає вебверсію.

Якщо порт 8081 зайнятий, зупини старий сервер або запусти `npm run ios -- --port 8082`. Посилання відображатимуть обраний порт. Для цього способу запускай застосунок через npm-команди вище.

Expo показує скорочене меню. Натисни `?`, щоб побачити всі команди, або `a`, щоб відкрити Android-емулятор/USB-пристрій. Вибір пристрою запускає той самий застосунок, а не створює окремий проєкт для кожної платформи.

На Android відкрий проєкт через QR-код в Expo Go. Телефон і комп’ютер мають бути в одній локальній мережі. Для Android-емулятора використовуй `npm run android`.

Expo Go на фізичному iPhone із SDK 57 вимагає входу в однаковий акаунт у CLI й застосунку навіть із `--offline`. Для нативного запуску на iPhone без акаунта Expo потрібна власна development build.
